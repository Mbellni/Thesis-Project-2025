# Thesis-Project-2025

This repository contains the full development, documentation, and research materials for my 2025 Master’s thesis project.  
The project explores **AI-driven persuasive behaviour in VR**, using an interactive **AI NPC** (Convai + Unreal Engine) to study whether short, immersive conversational experiences can influence users' beliefs about ambiguous statements.

Users interact with a human-like virtual agent inside VR, answer pre- and post-interaction questionnaires, and the system analyses belief change, presence, trust, and credibility.

---

## Project Overview

The goal of this project is to examine **how immersive environments and AI-driven dialogue influence user beliefs**.  
The system combines:

- **Unreal Engine VR experience** featuring a MetaHuman NPC  
- **Convai dialogue system** for real-time AI conversation  

---

## Features

- **VR Interaction System**  
  Fully interactive VR scenario built in Unreal Engine.

- **AI-Driven NPC (Convai)**  
  Natural conversational responses, persuasive dialogue behaviour, and real-time language model reasoning.

- **Belief-Change Measurement**  
  Users rate the likelihood of an ambiguous claim before and after the VR session.

- **Progress Journals**  
  Weekly journals documenting design, implementation, setbacks, iterations, and academic decisions.

## Getting Started

### Prerequisites

- **Unreal Engine 5.6.1**
- **VR headset** (Meta Quest via Link, or any PCVR-supported HMD)
- **Meta Quest Link App**
- **Git LFS** (required for UE assets)

---

### Clone the Repository

```bash
git clone https://github.com/Mbellini/Thesis-Project-2025.git
cd Thesis-Project-2025

```

Setup Instructions
1. Install Git LFS
git lfs install
git lfs pull

2. Open the Unreal Project

Navigate to the folder:

Thesis_Project/Thesis_Project.uproject


Open the project in Unreal Engine.

Enable plugins when prompted:

Convai

VR Template / VR Expansion

MetaHumans
